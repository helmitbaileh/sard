# السردية الفلسطينية | SARD

منصة رقمية تفاعلية وثائقية تعنى بتوثيق الرواية والقصص الإنسانية والتراث الفلسطيني المهدد بالاندثار.

---

## محتويات المشروع

- **`index.html`**:
  - **شاشة التحميل التفاعلية (Intro / Loader):** مستوحاة من حركة اليونسكو، تنبثق بين حرفي كلمة «سـ ـرد» رموز تراثية مصمتة بتسلسل متصل وحركة سلسة (حنظلة، جرة الفخار الكنعانية، غصن الزيتون، مفتاح العودة)، وتنتهي باتصال الكلمة «سرد» ثم الانتقال إلى الغلاف.
  - **الغلاف الرئيسي (Landing Page Cover):** تصميم فاتح وبسيط مستوحى من المتاحف العالمية (Rijksmuseum)، بخلفية بانورامية لجامع النصر وبرج المنارة في البلدة القديمة بنابلس مع حركة بارالاكس هادئة، وعنوان رئيسي ممدود ومرفوع.
- **`assets/`**:
  - تضم الصور والخلفيات عالية الدقة المستخدمة في الموقع.

---

## التشغيل المحلي

يمكنك معاينة المشروع مباشرة عبر متصفح الويب، أو تشغيل خادم محلي:

```bash
# باستخدام بايثون
python3 -m http.server 3000

# ثم فتح المتصفح على:
# http://localhost:3000
```
